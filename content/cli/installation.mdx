title: Installing the CLI
---

With the Litebase CLI you can issue authentication credentials, manage databases, execute SQL commands and more. The CLI is available for Linux, macOS, and Windows. You can download the latest version
using the following command in your terminal:

```shell
curl -sL https://litebase.com/install.sh | bash
```

Or, you can download the latest version from the [Litebase GitHub repository](https://github.com/litebase/litebase/releases).
